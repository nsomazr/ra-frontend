# Evidence Library Update — 26 September 2026

Added a team-wide Evidence Library to the REET P10354 field assessment system.

## Included
- New Evidence Library page in the main navigation.
- Search by filename, school, region, evidence stream and description.
- Filters for region, school and file type.
- View/preview for images, PDFs and text files.
- Download for all supported evidence files.
- Uses local IndexedDB while offline and the server evidence API when online.
- Links evidence back to the school and assessment reference where available.
- Server evidence responses now return the correct file content type and inline filename.
- Team-wide visibility is retained; no region-based access restriction was added.
