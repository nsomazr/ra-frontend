# Operational Controls Update — 2026-09-26

- Added clear Last Saved / Last Synced status in the shared header.
- Added server backup and restore controls under Administration.
- Added Team Leader review progression: Submitted → Under Review → QA Approved → Finalized.
- Finalized reports are locked for editing locally and during server synchronization.
- Draft/in-progress reports remain deletable.
- Server backup restore creates a backup of the current server data before replacement.
- Evidence files remain on the server during a data restore.

- Restricted draft/submit controls so Team Leaders cannot accidentally reset submitted or QA-approved reports back to draft.
